  // How far each zoom input moves the map. Every instance builds its map with
  // L.extend({ its own min and max zoom }, MAP_ZOOM_STEPS), so the step sizes
  // are one copy for the fleet while the zoom range stays each app's own.
  //
  // Leaflet's defaults move a WHOLE zoom level per + or - press, per keyboard
  // + or -, and per double-click, and a whole level doubles the scale of
  // everything on the map. Measured 2026-11-05 in the Illinois app, booted in
  // Chromium as Windows Chrome at 100% display scaling (the case Leaflet's
  // wheel maths is written per platform for), from zoom 12 in the Loop:
  //
  //                                   before   after
  //   one press of +                    1        0.5
  //   one mouse-wheel notch             1        0.5
  //   three notches 120 ms apart        2        1
  //   half a second of touchpad pinch   1.5      0.75
  //
  // The pinch row is a synthetic ctrl+wheel stream, gentle (2 px a frame) and
  // firm (8 px), five runs of each: before read 1.5 every time, after read 0.75
  // in 8 of 10 and 0.5 and 1.25 once each, because Leaflet drops part of a
  // burst that lands while the previous zoom is still animating.
  //
  // zoomDelta is the step for the buttons, the keyboard and a double-click.
  // Half a level is a scale change of about 1.4 times instead of 2.
  //
  // wheelPxPerZoomLevel is how much scrolling makes one level; Leaflet's 60
  // made a single notch of an ordinary Windows mouse a whole level. 120 halves
  // it on every platform, since Leaflet divides each platform's wheel delta by
  // its own factor before this number is applied.
  //
  // zoomSnap is the smallest zoom the map stops on. Leaflet rounds every wheel
  // burst UP to at least one snap, which is why a touchpad pinch moved the same
  // amount however hard it was pinched: the 40 ms bursts a pinch arrives in
  // are each far smaller than a snap. A quarter halves that floor, lets a
  // phone pinch settle within an eighth of a level of where the fingers let go
  // (a half step could jump a quarter), and keeps every zoom an exact binary
  // fraction, so a shared link carries z=13.25 and never a float tail. It must
  // divide every boot zoom (7.5 statewide, 11 in San Francisco), or Leaflet
  // rounds the opening view.
  //
  // zoomSnap 0, which would follow a pinch exactly, was measured too and not
  // taken: a half-second touchpad pinch then moved 0.04 to 0.17 of a level,
  // slow enough to read as broken, and every zoom a link carries would need
  // rounding.
  var MAP_ZOOM_STEPS = { zoomSnap: 0.25, zoomDelta: 0.5, wheelPxPerZoomLevel: 120 };

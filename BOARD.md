# districtry fleet board — retired 2026-09-29

The boards are no longer the record. Work on this repository is tracked in the
**Team manager for Claude sessions** project on claude.ai: its Overview holds
the fleet's state, and each state has its own thread there.

Until 2026-09-29 there were seven of these files — this one for work belonging
to no single state, and `il/`, `wi/`, `ia/`, `mi/`, `ny/` and `ca/BOARD.md`
beside their instances. They were hand-written by the sessions, updated in the
turn a piece of work finished, and read by nobody else; no gate, generator or
workflow ever read one. The hourly manager check-in that owned their *Tasks*
tables was paused the same day.

They are deleted rather than left to rot, because a board nobody updates is
worse than no board — the failure the root board itself recorded about
`ia/WATCH.md`. Everything they held is in this repository's history: to read a
board as it stood, `git show d0ed574:ia/BOARD.md` and the same for its
siblings.

This file stays as the signpost. Nothing writes to it.

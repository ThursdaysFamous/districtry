# WATCH.md — North Carolina's watch calendar and deferred measurements

Two things live here: *when to look* for boundary and roster changes in this instance's
sources, and the measurements this instance has taken but not yet acted on. The repo's
`docs/REDISTRICTING_RUNBOOK.md` is *what to do* when a boundary changes. Update the
"Last done" column each time you complete a row — a checkpoint with a stale date is a
checkpoint that didn't happen.

## Deferred at this instance's first PR — each one measured, none acted on

| What | The measurement | What would move it |
|---|---|---|
| **The instance is DARK and three things hold it that way.** It carries no `metros.json` entry, `'nc/**'` is blanket-excluded from the Pages deploy, and `scripts/build_legislator_pages.py` is deliberately NOT registered for `nc` — that generator fails outright on an instance `metros.json` does not carry, which is correct, so `nc/congress.html` and `nc/state-legislature.html` were deleted rather than shipped half-generated. **THE BLANKET `<tag>/**` FORM IS LOAD-BEARING, not a style choice**: it is what `validate_instance_registration.dark_instances()` reads, and four generators import that to tell a dark folder from an unregistered one. An anchored `/nc` excludes exactly the same files and is invisible to every one of them — which is how this row was first written, and `build_sitemap.py` would have listed three `nc/` paths the deploy does not publish. | `build_legislator_pages.py --check` FAILs with "INSTANCES names nc, which metros.json does not carry". | **Go-live, and all of it in the same change**: add `nc` to `metros.json` (with `--sync-fleet` for the `metro_explorers` tables); replace the blanket `'nc/**'` exclude with the siblings' narrow set (`nc/data/state nc/data/source nc/scripts`) so the build inputs stay unpublished; add `nc` to `build_legislator_pages.INSTANCES` and regenerate the two sub-pages; then re-run `build_sitemap.py`, `build_llms_txt.py`, `build_question_forms.py` and `node scripts/build_og_image.mjs --all`, each of which starts describing this instance the moment it stops being dark. |
| **There is no `nc/history.html`, and the masthead deliberately does not link one.** `history.html` is generated by `scripts/build_history_page.py` and is opt-in through the worksheet's `history_page` key; this instance carries no such key. The link was inherited from the page `nc/index.html` was cloned from and pointed at a file the repo does not contain — three dead links across `index`, `faq` and `sources`. | `scripts/validate_instance_assets.py` named all three; nothing else in the battery would have, because that gate's subject is same-origin references and the monthly link check only probes absolute URLs. | A history worth reading, which this instance will not have until it has shipped something a reader noticed. Add the `history_page` key and the three links back in the same change — and note the page's stat tiles are MEASURED at build time, so every weekly workflow that rewrites a file a tile counts must then regenerate it in the same run. |
| **NC OneMap serves a state address locator, and this instance does not use it.** `AddressNC/AddressNC_geocoder/GeocodeServer` answers unauthenticated with `Suggest` (real type-ahead), `findAddressCandidates` and `reverseGeocode`. Its native output is wkid 102719/2264 (NC State Plane, feet), so **`outSR=4326` is mandatory** or every result lands off the map; a suggestion resolves through its `magicKey`. Terms, behind every NC OneMap item's `licenseInfo`, are a **free and unrestricted use policy** — no written release, citation to CGIA requested. | Measured 2026-09-29, about a dozen requests. The locator is better than Photon for a North Carolina street address and knows nothing outside the state. | The blocker is not the locator, it is **where the geocoder lives**: the Photon endpoint is inside an ENGINE block, so swapping it for a per-instance locator is a fleet change to `engine/`, not an `nc/` change. It wants its own PR: a per-instance address locator with Photon kept for the unbounded sibling-metro lookup. Until then the app uses the fleet's bounded Photon like every other instance. |
| **Two counties use TOWNSHIP NAMES for their commissioner districts** (Gaston and Hyde, from the NCACC table). This instance ships a `county-subdivision` layer carrying every township, so those two counties' district geometry may already be on the map under a different name. | Not measured: whether Gaston's and Hyde's commissioner districts are unions of WHOLE townships is exactly the question `county-subdivision` cannot answer, and a township name matching a district name is not a statement that the two are the same polygon. | The county's own resolution, which NCGS 153A-22(f) leaves as a written description in the clerk's office. **Do not compose a district from townships because the names line up** — that is the inference this project has been wrong about before. Read the description first; a township-worded description that names whole townships would make these two counties the cheapest commissioner geometry in the state. |
| **All 100 counties' board form is answerable today with no geometry.** NCACC's *County Commissioner Election Methods* table gives every county's method — measured 39 at large, 23 district-labelled but elected countywide, 22 a combination, 16 purely by district, 587 commissioners, 61 using residency districts, 5 using limited voting. | Read from the published PDF (an Excel export — **ask for the workbook** rather than parsing the PDF). Not yet in any shipped file. | Its own PR: a `structure` field on the `county` card, the Illinois shape, statewide on day one. `ia/index.html` already handles both hard cases — a residency district elected countywide draws the district, says supervisors are elected countywide and names nobody on it; a mixed body shows the district member first and the at-large members under their own heading — so no card-wording question needs asking. |
| **Tribal governments are in scope in North Carolina and are NOT in this PR.** Adam made tribal government a fleet-wide mandate on 2026-09-29: a nation that elects from geographic districts belongs on the map like any other government. North Carolina has one federally recognised tribe, the **Eastern Band of Cherokee Indians** (the Qualla Boundary), plus the **Catawba** reservation, and a set of **state-recognised** tribes (Coharie, Haliwa-Saponi and others) that the Census carries as State Designated Tribal Statistical Areas. | **RELAYED, NOT MEASURED IN THIS THREAD — attributed rather than claimed.** The Kentucky planning thread's control run reports, from `TIGERweb/AIANNHA/MapServer` (Census 2020, layers 26-34): 2 federal reservations (Qualla Boundary, Catawba), 2 off-reservation trust lands, 11 state-designated tribal statistical areas, and NOTHING in the "Tribal Designated" layer. A coordinator note separately reports that the Eastern Band's tribal council is elected by township. Neither figure was fetched here; re-measure before either reaches a card. Two traps other threads have already paid for: these layers carry **no state field**, so filter by intersection with the state polygon and never by a bounding box; and **which TIGER layer a polygon sits in never tells you a nation's recognition status** — read the Federal Register notice. | **The fleet-wide tribal layer thread owns the build, not this instance.** Do not draw a tribal layer here: the concept, the card wording and the recognition question are being settled once for every state, and a seventh version of them decided in `nc/` is how this fleet's recurring two-readers defect starts. What this instance owes that thread is North Carolina's specifics, which is this row. If the Eastern Band's council really is elected by township, note that this instance already ships every township as `county-subdivision` — and note equally that **a township name matching a district name is not a statement that the two are the same polygon**, which is the same warning the Gaston/Hyde row above carries. The nation's own published districts are what would settle it. |
| **Do not classify a board's form from certified returns.** A first pass did and was wrong: NCGS 153A-58(c)/(d) allows a district-NAMED seat to be elected countywide, a `DISTRICT \d+` pattern misses township names, roman numerals and `EASTERN DISTRICT`, and a union of two generals double-classifies a county whose method changed by session law mid-window (Wake S.L. 2023-30, Watauga S.L. 2023-147). | Measured 2026-09-29. | Nothing — this is a standing warning, not a task. Only *which precincts voted in the contest* separates the two forms. |

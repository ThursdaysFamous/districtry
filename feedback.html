Describe what is wrong or what you would like, then file it as a GitHub issue or send it by e-mail. Either one opens a draft for you to read and edit first; nothing is sent until you send it. Every report gets a reply.

Reporting something on a map? Use the form inside the app instead (“Report a bug or leave a comment” at the foot of its panel): it attaches the point and layers you were looking at. The apps: Illinois, New York, San Francisco, Wisconsin, Iowa, Michigan.

Filled in with the page you came from. Change it if the problem is somewhere else.

Send by e-mail instead

A GitHub issue is public. The e-mail goes to adam@overberg.co. Either one carries what you wrote, the page address and your browser's user-agent string.

districtry answers one question: which civic districts contain the point you picked, and who represents you there. It reads public data, cites its sources, and never guesses an officeholder.
